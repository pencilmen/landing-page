# Landing Page

Portfolio website combining a Sci-Fi interactive preloader with smooth scroll typography and velocity-reactive image marquee.

## Features

- **Sci-Fi Preloader**: Circular SVG charge, terminal sequencing, double-wipe transition.
- **Scroll Hero**: Word-by-word morphing copy blocks driven by GSAP and ScrollTrigger.
- **Infinite Velocity Marquee**: Continuous image track accelerating with scroll speed.
- **Fully Responsive**: Tailored layouts for Desktop, iPad (tablet), and Mobile viewports.
- **Smooth Inertia Scrolling**: Powered by Lenis.

## Structure

- `index.html` — Page markup and ES module importmap
- `styles.css` — Futuristic design system, responsive breakpoints
- `script.js` — GSAP animations, Lenis controller, ScrollTrigger setup
- `netlify.toml` — Netlify deployment configuration
- `src/` — Marquee assets
